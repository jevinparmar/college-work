# Unit 2: Validation Controls and Rich Controls

This unit covers dynamic logic, input validations, state management, postback behavior, and rich controls in ASP.NET Web Forms.

| Program No | Folder / Page | Main Controls / Concepts Used |
|---|---|---|
| 06 | `06-Static-Login/Login.aspx` | `RequiredFieldValidator`, `ValidationSummary`, hardcoded credential verification |
| 07 | `07-Student-Admission/StudentAdmission.aspx` | `RegularExpressionValidator`, `RangeValidator`, `ValidationGroup`, `Server.HtmlEncode` |
| 08 | `08-Student-Marksheet/` | Session variables, page redirection (`Response.Redirect`), numeric conversion, double format |
| 09 | `09-Simple-Calculator/Calculator.aspx` | `CompareValidator`, `decimal.TryParse` verification, division-by-zero protection |
| 10 | `10-Hardware-Billing/Billing.aspx` | `ListBox`, `Image`, `AutoPostBack`, `SelectedIndexChanged` event, Rupees formatting |
