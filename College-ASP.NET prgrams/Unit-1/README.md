# Unit 1: Introduction and Web Server Controls

This unit covers basic controls, layout structures, and graphical interfaces in ASP.NET Web Forms.

| Program No | Folder / Page | Main Controls Used |
|---|---|---|
| 01 | `01-Login-UI/Login.aspx` | `Label`, `TextBox` (Password mode), `CheckBox`, `Button`, `HyperLink` |
| 02 | `02-Registration-UI/Registration.aspx` | `TextBox` (MultiLine, Date), `RadioButton`, `DropDownList`, `CheckBox`, `Button` |
| 03 | `03-Contact-Us-UI/ContactUs.aspx` | `TextBox`, `DropDownList`, `Button`, standard HTML address formatting |
| 04 | `04-Blog-UI/Blog.aspx` | `Button`, semantic HTML structure, internal CSS flexbox/grid layout |
| 05 | `05-Change-Password-UI/ChangePassword.aspx` | `TextBox`, `CheckBox` (AutoPostBack for password visibility toggle), `Button` |
